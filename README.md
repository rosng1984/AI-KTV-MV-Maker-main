# AI-KTV-MV-Maker
AI自动分离人声&伴奏，一键生成KTV字幕MV视频工具

## ⚠️ 重要说明
> 本仓库**仅存放源代码**，模型文件、FFmpeg程序、生成的音频视频缓存**没有放在Git仓库**，请自行准备。

## 功能简介
- AI人声/伴奏分离
- 自动歌词字幕对齐
- 合成KTV样式MV视频
- 支持批量处理歌曲

一、界面分区说明
1. 顶部搜索栏：搜歌曲名字 / 歌手，回车搜索；
◦ 📁 导入本地音视频文件（mp4/mkv/mp3/flac 等）
◦ 📄 加载本地 lrc 歌词文件
◦ ⬇ 下载选中：把列表选中歌曲导出音频 / KTV 视频

5. 底部控制栏：播放 / 暂停、上一首、下一首、进度条、音量滑块

1. 顶部搜索框输入歌名，回车搜索，或者直接点上方分类标签

4. 如果选 mp4/mkv（视频格式），会弹出素材设置窗口：

❌ 常见报错 & 排错指南
1. 启动直接报错 ModuleNotFoundError
👉 原因：依赖包没装全；重新执行 pip 安装命令，看报错缺哪个包单独装
2. FFmpeg 相关报错
👉 确认 ffmpeg.exe 在脚本同目录，或者加入系统 PATH；cmd 输入 ffmpeg -version 能正常输出版本才算生效
3. UVR 分离伴奏失败
1. 检查 UVR_MODEL_DIR 路径是否正确，模型文件名和下拉框一致
2. 模型文件损坏 / 没下载完整，重新下载 onnx 模型
3. 内存不足：MDX 模型吃内存，8G 内存容易失败，可以换轻量模型
分离失败会自动降级 FFmpeg 简易伴奏，效果很差，人声消不干净
4. 网站提示【需要人机验证】
👉 跟着弹窗浏览器完成验证码，验证完成点【验证完成，继续】，cookie 会自动保存到 cookies.json，一段时间内不用重复验证
5. 导出视频字幕不显示
👉 优先使用 MKV 格式；部分播放器对 ASS 字幕内置支持差；lrc 时间轴错乱会导致字幕错位，建议用高质量 lrc
6. 下载音频提示 403 / 下载不完整
👉 接口防盗链，重新点下载；频繁下载会触发网站风控，需要重新人机验证
7. 本地文件导入识别不到歌词
👉 自动匹配依赖 lrclib 接口，冷门歌曲匹配不到，手动准备 lrc 文件绑定
8. 打包 Nuitka 打包提示 audio-separator/torch 异常
audio-separator、torch 不适合打包，建议直接源码运行，不打包 exe
